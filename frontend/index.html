Project Architecture & Workflow

Technical blueprint for Dru AI's multi-model classification and analysis pipeline.

1. Breed Detection

Local TFLite classification engine.

  • Dataset Sources

    Curated Kaggle databases covering cattle, buffalo, cats, and dogs.

  • Fast Inference

    Optimized for on-device execution to ensure high-speed performance.

  • Primary Output

    Outputs precise breed taxonomy (e.g., "Amritmahal").

2. Health Analysis

Secondary visual pathology check.

  • Condition Screening

    Runs concurrently to flag potential visual medical issues or anomalies.

  • Early Warning

    Detects visible indicators of distress, skin disorders, or injury.

  • Flagging System

    Triggers secondary diagnostic workflows only if an issue is detected.

3. Gemini Enrichment

Contextual intelligence & solutions.

Characteristics Fetches food intake, life span, & milk production data.
Medical Cures Provides treatment solutions and care insights for flagged diseases.
